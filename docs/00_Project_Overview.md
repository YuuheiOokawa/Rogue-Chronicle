## 1. プロジェクトの目的・背景

### 1.1 目的
「1回15〜30分で完結し、負けても必ず前に進む」ローグライトRPGをWebブラウザ向けに個人開発で完成させる。
プレイヤーはランダム生成されるダンジョンに繰り返し挑戦し、ラン内では劇的なビルド成長を、ラン外では緩やかな永続成長を楽しむ。

### 1.2 背景
- Slay the Spire / Hades 等でローグライトの「短時間・高密度・繰り返し」のフォーマットは確立済みだが、**ブラウザで手軽に遊べるRPG寄りのローグライト**は選択肢が少ない
- 個人開発のため、リアルタイム性・大量アセット・運営型コンテンツを避け、**ターン制＋テキスト/UI主体の演出**（DEC-002, DEC-009）で開発コストを最小化する
- 課金・ガチャは恒久的に導入しない（DEC-016）。「遊びの純度」を差別化点とする
- 技術的にも Next.js + PostgreSQL のフルスタックTypeScript構成（DEC-004, DEC-005）の実践・ポートフォリオを兼ねる

### 1.3 プロジェクトゴール（MVP時点）
| 項目 | 目標 |
|---|---|
| プレイ体験 | 1ラン15〜30分で「挑戦→成長→リザルト→永続強化→再挑戦」のループが成立する |
| 完成範囲 | CORE_SPEC §11 のMVP範囲を100%実装（下記 §6 参照） |
| 品質 | 初期表示3秒以内 / API p95 500ms以内 / 戦闘結果はサーバー権威（DEC-007） |
| 運用 | Vercel + Neon で月額ほぼ無料枠に収まる構成 |

## 3. ジャンル・ターゲット・対応環境

### 3.1 ジャンル
**ローグライトRPG**（ラン型 / 永続成長あり / ターン制コマンドバトル DEC-002 / ノード選択型マップ DEC-003）

### 3.2 ターゲットユーザー像（ペルソナ）

**ペルソナA: 「スキマ時間ゲーマー」佐藤ユウタ（27歳・会社員）**
- 通勤電車（片道40分）と昼休みにスマホでゲームをする。据置機は積みゲー化
- Slay the Spire（スマホ版）とローグライト系を好むが、「ソシャゲのデイリー義務」に疲れている
- 求めるもの: **1プレイ15〜30分で完結**・中断再開が確実・課金圧なし・オフラインに近い気軽さ
- 本作の刺さりどころ: 途中保存＆再開（API-304）、ゲスト開始で即プレイ（DEC-006）、ガチャ非導入（DEC-016）

**ペルソナB: 「ビルド研究派」高橋ミナ（34歳・在宅エンジニア）**
- PCブラウザで作業の合間にプレイ。攻略Wikiより自力発見を好む
- Hades・Vampire Survivors経験者。シナジー発見と「当たりビルド」の再現に喜びを感じる
- 求めるもの: スキル×レリック×装備の組合せ深度、図鑑コンプ、実績、数値の透明性（計算式が読める）
- 本作の刺さりどころ: スキル20×レリック10×武器10の組合せ、行動予告（intent）による詰将棋的戦闘、図鑑（DEC-018）・実績

### 3.3 対応環境
| 項目 | 内容 |
|---|---|
| プラットフォーム | PCブラウザ / スマートフォンブラウザ（レスポンシブ対応） |
| 将来 | PWA化 → ネイティブ化を段階検討（MVPでは準備のみ） |
| 1プレイ時間 | **1ラン 15〜30分**（10階層、途中保存・再開可） |
| 通信 | 常時オンライン（戦闘計算・報酬はサーバー権威 DEC-007） |

### 3.4 開発方針
- **個人開発**（1名）。デザイン・運用コストを最小化する技術選定
- **MVP先行**: CORE_SPEC §11 の範囲を最初のリリースとし、遊べる状態を最短で作る
- **段階拡張**: デイリー/エンドレス/高難易度などのモードは、MVPのコアループ検証後に追加（05_Game_Design.md §7）
- ドキュメント駆動: docs/00〜29 の設計書を単一情報源（CORE_SPEC準拠）として実装する

## 5. MVP範囲サマリ（CORE_SPEC §11）

**含む**:
- キャラ3体（レイン/リリア/ガルド）/ ダンジョン1種「忘却の遺跡」/ 難易度Normalのみ / 10階層
- 敵: 通常5・エリート2・ボス1 / スキル20 / レリック10 / 武器10（防具・アクセは各3程度）
- ランダムイベント10 / ターン制戦闘 / ノード型マップ / スキル3択 / 途中保存・再開
- 永続強化ツリー12ノード / プレイヤーランク / 実績10個 / 図鑑
- ユーザー登録 + ゲスト / スマホ+PC対応 / Vercel + Neon

**除外（将来）**:
- PvP / ギルド / チャット / シーズン / リアルタイムマルチ / ガチャ / 課金 / ランキング
- 管理画面UI（DEC-013: シード+API土台のみ）/ 3D / ボイス / BGM（効果音は最小限△）
- デイリー・ウィークリー / エンドレス / タイムアタック / ボスラッシュ / 高難易度 / チャレンジ / 固定シード共有
- ミッション / SNSログイン / パスワード再設定（メール基盤が必要なため将来へ）
